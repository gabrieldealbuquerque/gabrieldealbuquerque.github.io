Acctsy

CTO · atuação atual

Transformar documentos contábeis em informação útil.

Atuo no desenvolvimento de um SaaS para escritórios de contabilidade, da arquitetura e das APIs à interface e à infraestrutura. O produto reúne processamento de documentos, análise financeira e integrações com inteligência artificial.

  • Backend com isolamento por escritório e permissões de acesso.
  • Fluxos de extração, processamento assíncrono e geração de relatórios.
  • Integração de modelos de IA, engenharia de prompt e RAG.

Python / FastAPI / Next.js / React / PostgreSQL / Redis / Docker

Por dentro da engenharia

A interface se comunica com o backend por uma camada BFF. O processamento usa filas persistentes, e o acesso aos dados considera o escritório, o cliente e as permissões de cada usuário.

Minha atuação conecta desenvolvimento full stack, integração de IA e operação: autenticação, APIs, persistência, processamento de arquivos e implantação com Docker.

TOV

Full stack · Meridian

Presença digital com autonomia para publicar.

Site institucional e gestão de conteúdo para o escritório Tristão de Oliveira e Valiatti. Desenvolvido com Pedro Henrique, pela Meridian, com páginas de serviços, artigos e um painel próprio de publicação.

React / TypeScript / Node.js / PHP / SQLite

Uma decisão de projeto

O mesmo frontend atende dois ambientes: backend Node.js para desenvolvimento e VPS, ou PHP para hospedagem compartilhada. O contrato da API é preservado entre eles.

O CMS inclui sessões com cookies HttpOnly, proteção CSRF e sanitização de conteúdo. Metadados por página, sitemap e RSS fazem parte da publicação dos artigos.

Meridian

Desenvolvimento em equipe

Construir junto, do primeiro contato à entrega.

Participo de um grupo independente de tecnologia formado por estudantes da UFES. Desenvolvemos sites, sistemas e automações para negócios, com contato direto entre quem precisa da solução e quem a desenvolve.

Astro / TypeScript / Interfaces web / Integrações

Da colaboração à entrega

A Meridian é um espaço de colaboração e aplicação prática do que estudamos. O projeto do TOV é uma dessas entregas, desenvolvido em conjunto com Pedro Henrique.

O site do grupo usa Astro e TypeScript. A Meridian é uma iniciativa independente, sem vínculo institucional com a UFES.
